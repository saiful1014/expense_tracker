# Change App Icon Plan

## Goal
Generate and apply a new colorful material-style app icon with a blue background using AI generation, then regenerate launcher icons with `flutter_launcher_icons`.

## Current State
- `pubspec.yaml` has `flutter_launcher_icons: ^0.13.1` configured
- Icon path: `assets/icon/app_icon.png`
- Android adaptive icon background: `#2196F3` (blue)
- iOS: `remove_alpha_ios: true`
- Current icon file is missing

## User Preferences
- Source: AI-generated
- Style: Colorful material
- Background: Blue
- Target output: 1024x1024 PNG

## Steps

1. Clarify the central icon element with the user (wallet, dollar sign, chart, etc.)
2. Generate a 1024x1024 PNG using an AI image generator with the confirmed prompt
3. Place the generated PNG at `assets/icon/app_icon.png`
4. If needed, update `adaptive_icon_background` in `pubspec.yaml` to match the generated background
5. Run `flutter pub get`
6. Run `flutter pub run flutter_launcher_icons`
7. Verify generated icons in `android/app/src/main/res/` and `ios/Runner/Assets.xcassets/`
8. Remove the unused `lib/services/network_exception.dart` if it's still present

## Clarifying Question
What central icon element should the AI generate? Examples:
- Wallet (matches the existing splash screen)
- Dollar sign / currency symbol
- Bar chart / analytics
- Credit card
- Receipt

This determines the exact AI prompt and ensures the final icon aligns with the app's expense-tracking purpose.
